# Paper

> Paper is a modern design tool built on HTML & CSS standards. Design on a canvas, export as React code, and connect AI agents that can read and write to your designs via MCP. Unlike legacy tools that draw abstract representations of interfaces, Paper renders actual HTML and CSS — so there's nothing for agents to interpret or guess.

Paper bridges design and code with a bidirectional workflow. What you design is real HTML/CSS, and what you code appears on the canvas. AI agents connect through the Model Context Protocol (MCP) to see, create, and edit designs programmatically. The canvas speaks the same language agents are trained on — zero translation loss.
